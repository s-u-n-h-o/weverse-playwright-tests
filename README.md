# Weverse Playwright E2E 테스트


## 프로젝트 소개

[Weverse](https://weverse.io) 웹 서비스를 대상으로 한 Playwright 기반 자동화 테스트 프로젝트입니다.
실제 운영 중인 서비스를 대상으로 로그인, 검색, 아티스트 커뮤니티, 다국어 전환 등 핵심 사용자 플로우를 검증합니다.


## 주요 기능 (테스트 커버리지)

각 테스트는 TC ID를 부여해 테스트케이스 문서와 1:1로 추적 가능하도록 작성했습니다.

| 영역 | 파일 | 설명 |
| --- | --- | --- |
| 로그인 | `e2e/login.spec.ts` | LGN-001 이메일/비밀번호 로그인 성공, LGN-002 잘못된 비밀번호 에러 노출 |
| 로그인 세션 유지 | `e2e/mypage.spec.ts` | 저장된 세션으로 재접속 시 로그인 상태 유지 확인 |
| 홈페이지 | `e2e/homepage.spec.ts` | 로고, 메뉴, 배너, Shop 링크 등 주요 UI 요소 노출 확인 |
| 커뮤니티 검색 | `e2e/search.spec.ts` | SEARCH-001~005 그룹/아티스트명 검색, 초성 검색, 검색어 삭제 시 결과 초기화 등 |
| 아티스트 커뮤니티 | `e2e/community.spec.ts` | COMMUNITY-001~003, 005, 007 커뮤니티 가입, Merch 반영 지연, 게시글 좋아요, 미가입 시 가입 유도, 비로그인 접근 제한 |
| 다국어 변경 | `e2e/i18n.spec.ts` | I18N-001~003 서비스 언어/번역 언어 전환 및 두 설정의 독립 동작 확인 |

## 기술 스택

- **[Playwright Test](https://playwright.dev/)**
- **TypeScript** — 정적 타입 기반 테스트 코드 작성
- **dotenv** — 로컬 환경변수(`.env`) 관리
- Chromium, Firefox 2개 브라우저 프로젝트로 크로스 브라우저 검증


## 시작 가이드

### 1. 설치

```bash
npm install
npx playwright install --with-deps
```

### 2. 환경변수 설정

로그인이 필요한 테스트를 위해 프로젝트 루트에 `.env` 파일을 만들고 위버스 계정 정보를 입력합니다.

```env
WEVERSE_EMAIL=your-email@example.com
WEVERSE_PASSWORD=your-password
```

### 3. 로그인 세션 생성 (최초 1회)

위버스는 이메일 인증코드를 요구하므로 로그인은 완전 자동화할 수 없습니다. 아래 명령으로 브라우저를 띄운 뒤, 이메일로 온 인증코드를 창에 직접 입력하면 세션이 `playwright/.auth/user.json`에 저장됩니다.

```bash
npx playwright test e2e/auth.setup.ts --headed
```

이후 로그인이 필요한 테스트들은 이 저장된 세션을 재사용하므로 매번 로그인할 필요가 없습니다. 세션은 시간이 지나면 만료될 수 있으며, 이 경우 위 명령을 다시 실행하면 됩니다.


## 한계 및 개선 과제
- 여러 테스트가 동시에 같은 계정을 건드리다가 서로의 결과를 덮어써버리는 문제를 `test.describe.configure({ mode: 'serial' })` 사용하여 수정
- 이메일 인증코드처럼 자동화할 수 없는 로그인 단계는 **1회성 수동 스크립트**로 분리
  
- **스테이징 환경 부재**: 별도 테스트 환경 없이 실제 서비스 계정으로 테스트를 수행합니다. 커뮤니티 가입처럼 되돌리기 어려운 액션이 있는 테스트는 재실행 시에도 안정적으로 동작하도록 미가입 아티스트 후보군을 순회하는 방식으로 구현했습니다.
- **COMMUNITY-004 skip**: 좋아요 반복 클릭 시 노출되는 접근 제한 메시지는 실사용 환경에서는 확인했으나, 계정의 누적 요청 이력에 따라 조건이 달라지는 것으로 추정되어 자동화 테스트에서 결정론적으로 재현하지 못해 현재 스킵 처리되어 있습니다.
- **로그인 자동화 한계**: 이메일 인증코드 입력 단계가 있어 최초 로그인은 수동 개입이 필요합니다.
